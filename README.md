# Quant Room

Open the website: https://xujingxiang19883.github.io/quant-room/

Choose one of five books, select a question, read the solution, and click **Mark complete** when finished. Use the header buttons to adjust text size or switch light/dark mode. Library and question columns can be collapsed for reading space.

Completion and display preferences are saved in your current browser. Clearing browser data removes them; they do not synchronize across devices or with the previous ChatGPT Site address.

To import completion records from the original site, open this website in the same browser/profile used for the original site. Click **同步原站进度**, then **发送到新站** in the original-site popup. Existing records are merged and deduplicated, with a local backup before import. You can repeat this transfer later; it is not automatic cloud synchronization.

This repository contains the published static website. Original PDF books, local caches, credentials, and the private source repository are not included. All website fonts, formulas, data, and images are served locally without third-party CDN dependencies.
